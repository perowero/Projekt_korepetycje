Tutoring Management System Design
The application distinguishes between two main user roles: Student and Teacher.

Student Features:
  - lesson calendar
  - lesson payments
  - downloading shared files
  - reviewing lesson summaries and homework assignments

Teacher Features:
  - adding students
  - adding lessons
  - lesson calendar
  - sharing files with students
  - adding lesson descriptions and homework assignments
  - adding and managing payments

Further feature enhancements and expansions are planned for future releases.

Technical Specifications

Backend:
  - Programming Language: Java (using Spring Boot framework)
  - Authentication: Spring Security
  - Database: MySQL

Frontend:
  - Technology: React
  - Styling & UI: Tailwind CSS
    

Projekt systemu zarządzania korepetycjami.

Aplikacja rozróżnia podział na dwie role: ucznia i nauczyciela.

Uczeń ma dostęp do następujących funkcjonalności:
  - kalendarz lekcji
  - opłat za lekcje
  - pobieranie udostępnionych plików
  - sprawdzanie podsumowań lekcji i prac domowych

Nauczyciel ma dostęp do następujących funkcjonalności:
  - dodawanie uczniów
  - dodawanie lekcji
  - kalendarz lekcji
  - udostępnianie plików uczniom
  - dodawanie opisów lekcji i prac domowych
  - dodawanie płatności i zarządzanie nimi

W planach jest rozwój aplikacji o dalsze funkcjonalności
